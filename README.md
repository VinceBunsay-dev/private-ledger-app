# Private Ledger App

A full-stack personal and financial ledger web application built with React and Vite, backed by a relational MySQL database (`private_ledger`) to track deposits, withdrawals, packages, payment methods, and full ledger history.

## Key Features
- **Financial & Ledger Tracking:** Record and monitor deposits, withdrawals, and chronological ledger history.
- **User & Package Management:** Manage user profiles, payment methods, and assigned packages.
- **Structured Database Schema:** Backed by normalized MySQL tables (`users`, `deposits`, `withdrawals`, `ledger_history`, `payment_methods`, and `user_packages`).
- **Fast Modern UI:** Built with React and Vite for responsive navigation and quick state updates.

## Tech Stack
- **Frontend:** React, Vite, HTML5, CSS3, JavaScript
- **Backend / API:** Node.js / Express (or your backend service)
- **Database:** MySQL (`private_ledger`)
